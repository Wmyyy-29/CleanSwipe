# Security Policy / 安全政策

## Reporting a vulnerability

Please do not report security or privacy vulnerabilities in a public issue. Use GitHub's **Report a vulnerability** feature in the repository's Security tab. Include the affected version, reproduction steps, impact, and a suggested mitigation if available.

Do not include personal photos, photo metadata, Apple account details, device identifiers, certificates, or provisioning profiles in a report.

## Supported version

This is an early open-source demo. Security fixes are applied to the latest revision on the default branch; older revisions are not maintained separately.

## 中文

请不要在公开 Issue 中披露安全或隐私漏洞。请在 GitHub 仓库的 **Security** 页面使用 **Report a vulnerability** 私密提交，并说明受影响版本、复现步骤、影响和可能的修复建议。

报告中不要包含个人照片、照片元数据、Apple 账户信息、设备标识、证书或描述文件。本项目目前是早期开源 Demo，仅维护默认分支的最新版本。
